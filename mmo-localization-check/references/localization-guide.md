# 현지화 문자열 가이드

## 목차

1. 표 형식
2. 규칙 설명
3. 폭 계산
4. 검사가 보지 못하는 것
5. 문자열 작성 원칙
6. 확장 지점

## 1. 표 형식

한 행이 문자열 하나다. 언어마다 열을 둔다.

| 열 | 의미 |
|---|---|
| `key` | 문자열 키. 코드와 데이터가 이 키로 찾는다. 예: `ui.ok`, `quest.kill` |
| `ko` | 원문 (설정의 `source_language`) |
| `en`, `ja`, ... | 번역. 필수 언어와 선택 언어는 설정에서 정한다 |
| `max_width` | 이 문자열이 들어갈 UI의 폭 제한. 없으면 빈칸 |

자리표시자 형식: `{0}`, `{name}`, `%d`, `%s`. 서식 태그: `<b>...</b>` 같은 꺾쇠 태그.
언어마다 어순이 다르므로 자리표시자의 순서는 달라도 된다. 종류와 개수는 같아야 한다.

## 2. 규칙 설명

| ID | 의미 | 게임에서 생기는 일 |
|---|---|---|
| LOC001 | 키가 비었거나 중복된다 | 뒤 행이 앞 행을 덮어쓰거나 찾지 못한다 |
| LOC002 | 원문이나 번역이 비어 있다 | 빈칸이나 키 이름이 그대로 보인다. 선택 언어는 warning |
| LOC003 | 자리표시자나 서식 태그가 원문과 다르다 | 값이 들어가지 않거나 태그가 글자로 보인다 |
| LOC004 | 폭이 `max_width`를 넘거나, 제한이 없는데 원문보다 훨씬 길다 | 글자가 잘리거나 UI 밖으로 나간다 |
| LOC005 | 번역이 원문과 같다 | 번역이 빠졌을 수 있다. 고유명사와 약어는 정상 |
| LOC006 | 원문에 없는 앞뒤 공백이나 연속 공백이 있다 | 정렬이 어긋나 보인다 |
| LOC007 | 중괄호나 서식 태그가 닫히지 않았다 | 서식 처리가 실패해 문장 전체가 깨진다 |
| LOC008 | 게임이 쓰는 키가 표에 없다 | 키 이름이 화면에 그대로 보인다 |

## 3. 폭 계산

- 한글, 한자, 가나 같은 전각 문자는 2, 그 밖의 문자는 1로 센다 (설정의 `wide_char_width`).
- 자리표시자와 서식 태그는 세지 않는다. 실제로 들어갈 값의 길이는 알 수 없으므로 여유를 두고 제한을 잡는다.
- `max_width`가 있으면 그 값과 비교한다. 원문이 넘어도 지적한다.
- `max_width`가 없으면 원문 폭의 몇 배를 넘는지 본다 (설정의 `expansion_limit`, 언어별 지정 가능).
  원문이 아주 짧으면(`expansion_min_source_width` 미만) 이 비교를 하지 않는다. "확인"이 "Confirm"이
  되는 정도의 차이는 정상이기 때문이다.

한국어 원문을 영어나 독일어로 옮기면 글자 수는 늘지만 폭은 비슷하거나 조금 넓어지는 경우가 많다.
버튼과 탭처럼 좁은 UI에는 `max_width`를 꼭 적는다.

## 4. 검사가 보지 못하는 것

- 번역의 정확성, 어조, 용어 통일
- 실제 폰트에서의 폭과 줄바꿈
- 복수형, 조사(은/는, 이/가) 처리가 문법에 맞는지
- 이미지 안의 글자, 음성
- 자리표시자에 실제로 들어갈 값의 길이

## 5. 문자열 작성 원칙

- **문장을 코드에서 이어 붙이지 않는다.** `"보상: " + 아이템 이름`이 아니라 `보상: {item}` 하나로 둔다.
  언어마다 어순이 달라 이어 붙인 문장은 번역할 수 없다.
- **자리표시자는 이름으로 쓴다.** `{0}`보다 `{monster}`가 번역자에게 뜻을 전한다.
- **조사가 붙는 자리표시자는 한국어 조사 처리를 정한다.** `{monster}을(를)`처럼 병기하거나, 받침에 따라
  고르는 기능을 쓴다.
- **숫자와 단위를 문자열에 박지 않는다.** 날짜, 통화, 천 단위 구분은 언어마다 다르다.
- **키는 용도를 드러내게 짓는다.** `ui.`, `quest.`, `item.`, `skill.` 같은 접두사로 나눈다.
  같은 문장이라도 쓰이는 곳이 다르면 키를 따로 둔다.
- **지운 키는 표에서도 지운다.** 쓰이지 않는 키가 쌓이면 번역 비용이 계속 든다.
- **서버가 보내는 메시지는 키와 값으로 보낸다.** 서버가 완성된 문장을 보내면 클라이언트 언어로 보여 줄 수 없다.

## 6. 확장 지점

- **새 언어:** 표에 열을 추가하고 설정의 필수 또는 선택 언어에 넣는다. 처음에는 선택으로 두고
  번역률이 차면 필수로 올린다.
- **용어집 검사:** 고유명사(지명, 스킬 이름)가 언어별로 정해진 표기와 같은지 보는 규칙을 추가한다.
- **사용 키 수집:** 코드와 데이터에서 키를 뽑는 스크립트를 프로젝트에 맞게 만들어 `--used-keys`에 준다.
- **언어별 금지 문자:** 폰트에 없는 글자를 찾는 규칙을 추가한다. 폰트의 글자 목록이 필요하다.
