# 스킬 로드맵

아직 만들지 않은 영역이다. 위에서부터 우선순위가 높다.
각 항목의 "코드로 만들 수 있는 부분"이 스킬의 `scripts/`가 된다.

## 다음 차례

| 영역 | 스킬 이름(안) | 코드로 만들 수 있는 부분 | 먼저 정해져야 하는 것 |
|---|---|---|---|
| 부하 테스트 | `mmo-load-test` | 봇 접속 시나리오 실행, 서버 지표 수집과 판정 | 게임 서버 종류, 목표 동시 접속 |
| 전투/스킬 | `mmo-combat-gas` | 스킬 데이터 검증(쿨다운, 비용, 계수), 어빌리티 코드 규칙 검사 | 전투 방식 |
| 인벤토리/경제 | `mmo-economy-check` | 재화 유입/소모 시뮬레이션, 거래 로그 이상 탐지 | 재화 종류, 거래 방식 |
| 월드/스트리밍 | `ue-world-streaming-check` | 월드 파티션 셀 크기와 메모리 예산 검사, 스트리밍 히치 측정 | 월드 구성 |
| 빌드/CI | `ue-build-pipeline` | 위 검사들을 묶은 커밋 전/야간 빌드 스크립트 | 소스 컨트롤 종류 |

## 그다음

| 영역 | 스킬 이름(안) | 내용 |
|---|---|---|
| 퀘스트/내러티브 | `mmo-quest-check` | 선행 퀘스트 순환, 도달 불가 퀘스트, 보상 참조 검사 |
| 캐릭터/애니메이션 | `ue-character-pipeline` | 스켈레톤 규격, 애니메이션 예산, 군중용 LOD |
| 라이팅/렌더링 | `ue-lighting-budget` | MegaLights/Lumen 설정 기준, 장면별 GPU 예산 |
| UI | `ue-ui-check` | 위젯 수, 틱 사용, 현지화 누락 검사 |
| 보안/치트 방지 | `mmo-security-review` | 서버 검증 누락 탐지 확장, 패킷 빈도 제한 점검 |
| 라이브 운영 | `mmo-liveops` | 패치 절차, 점검 체크리스트, 롤백 절차 |
| 현지화 | `mmo-localization-check` | 누락 키, 길이 초과, 변수 불일치 검사 |

## 스킬로 만들 가치가 있는지 판단하는 기준

- 같은 확인을 세 번 이상 반복했다.
- 통과/실패 기준을 수치나 규칙으로 적을 수 있다.
- 틀렸을 때 비용이 크다(서버 장애, 경제 붕괴, 출시 지연).

셋 중 둘 이상이면 만든다. 판단이 주관적이고 매번 다른 일은 스킬보다 사람 리뷰가 맞다.
