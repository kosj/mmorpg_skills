# 규칙 설명과 수정 방법

| ID | 의미 | 고치는 방법 |
|---|---|---|
| LINK000 | 같은 종류에 `id`가 두 번 나온다 | 한쪽 이름을 바꾼다. 콘텐츠 팩 파일끼리 겹치는 경우가 많다 |
| LINK001 | 없는 항목을 참조한다 | 오타를 고치거나 참조 대상을 먼저 추가한다 |
| LINK002 | 소켓이 스켈레톤에 없다 | 스켈레톤 에셋에 소켓을 추가하고 규약의 `sockets`에도 적는다. 파츠 이펙트라면 파츠의 `provides_sockets`에 적는다 |
| LINK003 | 이동 모드에 필요한 애니메이션 상태가 세트에 없다 | 애니메이션을 만들어 세트의 `states`에 추가한다. 탑승자 상태라면 좌석의 `rider_anim_set`에 추가한다 |
| LINK004 | 애니메이션 세트나 IK 프로필의 스켈레톤이 주인과 다르다 | 맞는 세트를 지정하거나 리타기팅한 세트를 새로 만든다 |
| LINK005 | 탈것에 좌석이 없거나 탈 수 있는 캐릭터가 없다 | 좌석을 추가하거나, 캐릭터 스켈레톤용 탑승 애니메이션 세트를 만든다 |
| LINK006 | 들어갈 수 없거나 기본 모드로 돌아올 수 없는 이동 모드가 있다 | `movement_modes`의 `transitions`에 전환을 추가한다. 비행이면 착지 전환이 빠진 경우다 |
| LINK007 | 공중 모드에 발 IK가 켜져 있거나, 발 IK를 쓰는 모드인데 IK 프로필이 없다 | 공중/수영 모드는 `foot_ik`를 끈다. 지상 모드는 스켈레톤에 발 배치 IK 프로필을 만든다 |
| LINK008 | 부착 이펙트 문제: 예산 초과, 풀링 꺼짐, 월드 이펙트를 소켓에 부착 | 이펙트 수를 줄이거나 비용이 낮은 버전을 쓴다. 부착 이펙트는 풀링을 켠다 |
| LINK009 | 날씨마다 파라미터 키가 다르거나, 날씨 전환 그래프가 끊겨 있다 | 빠진 키를 기본값으로 채운다. 고립된 날씨에 들어오고 나가는 전환을 추가한다 |
| LINK010 | 날씨가 이동 모드를 막는데 그 모드에서 빠져나갈 전환이 없다 | 강제 착지에 쓸 전환을 추가한다. 없으면 폭풍이 시작될 때 비행 중인 플레이어를 처리할 수 없다 |
| LINK011 | 바이옴의 배치 밀도가 예산을 넘는다 | 레이어 밀도를 낮추거나 Nanite 에셋으로 바꾼다 |

## 지적을 작업 목록으로 읽는 법

검사기 출력은 "틀렸다"가 아니라 "아직 없다"인 경우가 많다. 확장을 계획할 때는 지적 하나가 작업 하나다.

- `LINK003 ... 모드 fly에 필요한 상태가 anim_set AS_Horse에 없음: takeoff, fly_idle, fly_move, fly_land`
  → 말 스켈레톤용 비행 애니메이션 4개 제작
- `LINK003 ... 좌석 0: 모드 fly에 필요한 탑승자 상태가 AS_Human_Ride_Horse에 없음: ride_takeoff, ride_fly, ride_land`
  → 사람 스켈레톤용 비행 탑승 애니메이션 3개 제작
- `LINK002 ... 소켓 'wing_tip_l'이(가) 스켈레톤 SK_Horse에 없음`
  → 날개 본과 소켓 추가 (스켈레톤 변경은 기존 애니메이션 전체에 영향을 주므로 범위를 따로 확인)

## 검사기가 보지 못하는 것

- 규약에 적힌 소켓, 상태, 에셋이 프로젝트에 실제로 있는지
- 애니메이션의 품질이나 길이, 이펙트의 실제 GPU 비용
- 파츠 메시끼리 겹치거나 뚫고 나오는 문제
