# 캡처 조건과 방법

## 측정 조건 (판정에 쓰는 캡처)

- **빌드:** 패키징한 Development 또는 Test 빌드. 에디터(PIE) 측정은 참고용으로만 쓴다.
- **PC:** 목표 사양 PC. 사양(CPU, GPU, RAM, 해상도, 그래픽 프리셋)을 `--label`에 적는다.
- **프레임 제한 해제:** 수직동기화와 프레임 제한을 끈다. 콘솔에서 `r.VSync 0`, `t.MaxFPS 0`.
- **구간 고정:** 매번 같은 맵, 같은 경로로 측정한다. 가능하면 시퀀스나 자동 이동 경로를 쓴다.
- **길이:** 최소 600프레임. 기본 예산은 앞 120프레임을 워밍업으로 버린다.

## MMORPG에서 반드시 따로 재는 장면

혼자 필드를 걷는 장면만 재면 통과해도 의미가 없다. 아래를 각각 캡처하고 `--label`에 장면을 적는다.

- **마을:** 플레이어가 가장 많이 모이는 곳. 보이는 캐릭터 수 상한까지 채운 상태.
- **대규모 전투:** 목표 인원이 동시에 스킬을 쓰는 상태. 이펙트와 이름표가 가장 많다.
- **필드 이동:** 탈것 최고 속도로 지역 경계를 넘는다. 스트리밍 히치(PERF004)를 본다.
- **던전 보스전:** 파티 인원 전체와 보스 패턴 이펙트.

실제 플레이어를 모으기 어려우면 봇이나 더미 캐릭터로 채운다. 채운 인원 수를 `--label`에 적는다.

## 방법 1: 콘솔 명령

실행 중인 게임 콘솔에서:

```
csvprofile start
(측정 구간 플레이)
csvprofile stop
```

정해진 프레임 수만 캡처하려면 `csvprofile frames=3600`.

## 방법 2: 실행 인자

시작부터 N프레임을 캡처한다.

```
<Game>.exe <Map> -csvCaptureFrames=3600
```

## 방법 3: 에디터에서 빠르게 확인 (참고용)

Unreal MCP의 콘솔 도구로 `csvprofile start` / `csvprofile stop`을 보낸다.
PIE가 실행 중이어야 한다. 결과는 에디터 부하가 섞인 값이므로 보고할 때 그 사실을 적는다.

## 결과 위치

`<Project>/Saved/Profiling/CSV/` 아래에 날짜와 시간 이름으로 생긴다.
패키징 빌드에서는 그 빌드의 `Saved` 폴더에 생긴다.

## GPU 시간이 비어 있을 때

`GPUTime` 열이 없거나 0이면 GPU 통계 수집이 꺼져 있는 것이다. 판정은 GEN001로 건너뛴다.
GPU 세부 항목까지 보려면 캡처 전에 콘솔에서 `r.GPUCsvStatsEnabled 1`을 켠다.
